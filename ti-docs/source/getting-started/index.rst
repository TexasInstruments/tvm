###############
Getting Started
###############

.. note::

    The `TI Edge AI Cloud <https://www.ti.com/tool/TI-EDGE-AI-CLOUD#overview>`_ is a free online service used to evaluate and benchmark 
    accelerated deep learning inference on :term:`TDA4 family` processors.  TVM is one of the frameworks supported by the TI Edge AI Cloud. If you are 
    interested in evaluating TVM without having to install any software or purchase an evaluation board, you can use this service.

This chapter lists the steps required to install the TVM framework, compile models, and run inference on a TI evaluation board (EVM).
