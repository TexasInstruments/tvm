###############
Getting Started
###############

.. note::

    The `TI Edge AI Cloud <https://www.ti.com/tool/TI-EDGE-AI-CLOUD#overview>`_ is a free online service to evaluate and benchmark 
    accelerated deep learning inference on TDA4x processors.  TVM is one of the frameworks supported by TI Edge AI Cloud. Users
    interesting in evaluating TVM without having to install any software or purchase an evaluation board can use this service.

This chapter lists the steps required to install the TVM framework, compile models and run inference on a TI evaluation board (EVM).
