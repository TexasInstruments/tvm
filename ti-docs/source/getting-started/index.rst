###############
Getting Started
###############


TVM is one of the open source runtimes supported by TI for Edge AI applications meant to run accelerated inference on :term:`TDA4 and AM6x families` processors. 

This chapter lists the steps required to install the TVM framework, compile models, and run inference on a TI evaluation board (EVM).
